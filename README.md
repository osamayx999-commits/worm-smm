# Worm SMM — Frontend Prototype 1.0

واجهة أولية عربية RTL متجاوبة مبنية باستخدام HTML وCSS وJavaScript فقط.

## التشغيل
- فك ضغط الملف.
- افتح `index.html` في المتصفح.
- لا تحتاج الواجهة إلى تثبيت حزم أو تشغيل Backend.

## الموجود
- صفحة رئيسية وهوية Worm SMM.
- نموذج دخول مدير تجريبي (ليس مصادقة حقيقية).
- لوحة تحكم بتصميم تجريبي.
- بطاقات المنصات.
- تنقل تفاعلي داخل القائمة.

## غير الموجود بعد
- لا توجد قاعدة بيانات أو API خلفي.
- الأرقام والطلبات المعروضة بيانات وهمية للمعاينة فقط.
- لا يوجد نظام دفع أو تنفيذ طلبات.
- لا تحفظ الواجهة كلمات المرور.

## ملاحظة
خط Google Fonts اختياري ويتطلب اتصالاً بالإنترنت؛ توجد خطوط بديلة محلية في المتصفح.
